Reflection

Through this practice, I learned that CSS inheritance allows certain styles to flow from parent elements down to their children unless a child has a more specific style of its own. However, not every CSS property is inherited. I also learned how important selectors are when I want to target a specific element. I can use an element, class, or ID selector depending on what I want to change. When multiple CSS rules affect the same element, specificity hekps determine which rule is applied. If the rules have the same specificity, the rule that appears later takes priority.

In order to add my website navigation, I had to move the title into its own section so I could place the navigation inside the header. I was nervous to change my existing HTML, but once I did, it was easier than I expected. While adding the main navigation to every page, I realized how helpful it is to organize each page similarly so I can easily make changes across the site. Working with relative paths was frustrating at first, but after completing the navigation, I felt much more comfortable moving between folders and linking my pages together and easily adjusting when I wanted to change the name of a page/folder/etc.
