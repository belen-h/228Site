Process Reflection

I started this exercise by reviewing the HTML structure and organizing the spacing in my code so I could clearly read and better understand where the IDs and classes called out in the CSS were placed. After that, I bagan and learned that adding display: flex to a parent element turns it into a flex container, and its direct children become flex items. By default, Flexbox arranges these items in a row rather than a column.

One of the most interesting parts was experimenting with flex-wrap and percentage widths. I could see how these properties affected the layout when resizing the browser window. This was especially exciting because I've been wanting to make my Interactive Sketchbook more responsive to different screen sizes.

While experimenting with the h1 inside the header, I used temporary background colors to see how much space the element occupied. I was surprised by how align-self affected its position. When I tried aligning it toward the bottom, the text appeared higher than I expected, while the element seemed to occupy the entire height of the header. I eventually decided to use align-self: center because it gave me the alignment I wanted.

I also noticed that assigning widths to the child elements changed how they behaved when wrapping. I'm still experimenting with how widths, spacing, and wrapping work together, especially when the available screen space becomes smaller.
