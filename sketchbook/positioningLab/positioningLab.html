positioning elements

Static

default, as-is behavior

Relative

this positions a child relative to its parent. by giving an element a relative position, we can place it outside the normal flow of where it would be- but it still impacts other elements

Absolute

this takes the element out of the line up and no longer impacts elements around it, BUT you have to apply position:relative to a parent container

Fixed

positioned in relation to the browser window, it just stays put!

***Sticky***

this one is a little more advanced, and we won't get into it yet, but perhaps challenge yourself and your project to see if you can figure it out?


Next up: z-index

this is how we control layering when we are using positioning. if an element has a position, you can add a z-index, the larger the number the closer to the top.
0=bottom 100=top
think of z-index like the “bring to front” or “send to back” in design software.

Process Reflection

October 28, 2026

This exercise helped me understand how quickly positioning can change a layout just by adjusting a few values in CSS. I enjoyed experimenting with different numbers and seeing which direction the elements moved in the browser. Using the temporary background colors was helpful because I could see where the containers were and how they interacted with other elements.

Relative and fixed positioning made the most sense to me. Absolute positioning was a little more confusing, but understanding parent-child relationships helped me see how an element's position depends on its container. I still feel like I need more practice with positioning values to become comfortable using it on my own.

The z-index property was one of the easiest concepts to understand because it reminded me of arranging layers in Photoshop. Once I understood how it worked, I could quickly change which elements appeared in front of or behind others.

One challenge was the fixed footer overlapping the text and making it difficult to read. I experimented with its width and eventually reduced the font size to make the overlap feel more intentional. I also moved the circles farther to the right so they wouldn't interfere with the main content.

This exercise made me more interested in experimenting with positioning in my Interactive Sketchbook, although I can see how easily it could cause readability problems if I'm not careful.
